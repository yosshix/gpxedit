# GPXedit

ROADSTOCK（iOSアプリ）などで書き出したGPXファイルを読み込み、**地図と時間スライダーで区間を切り出して**、新しいGPXとして書き出すWebアプリです。書き出したGPXは、Reliveなどのアプリに取り込めます。

- 公開ページ：<https://yosshix.github.io/gpxedit/>
- iPhone / iPadのSafariで使えます（Mac・Windows・Androidのブラウザでも動作します）。
- ファイルの処理はすべて端末内で行い、GPXを外部に送信しません。

## 主な機能

- GPXの読み込みと、ファイル情報の確認（開始・終了日時、測位ポイント数、平均間隔、距離、平均速度、最高速度、最高標高、トラック名、Creator、ウェイポイント）
- 地図表示（国土地理院タイル：淡色地図・標準地図・航空写真／OpenStreetMap／背景なし）。選んだ地図は次回も引き継がれます
- 速度グラフの表示（経過時間／点の順の切り替え）
- 開始位置・終了位置の指定と、途中区間の削除（複数指定可）
- 削除した部分の扱いの選択（トラックを分ける／1本に連結する）
- 範囲内のウェイポイント（出発・停車地点）の引き継ぎ
- GPXの保存（共有シート／ファイル）と、内容のコピー

## 使い方

1. **GPXを開く**
   - 「GPXを開く」を押し、「ファイル」からGPXを選びます（パソコンでは、画面へのドラッグ＆ドロップも可能です）。
2. **ファイル情報を確認する**
   - 「GPXファイルの情報」のダイアログが出ます。内容を確認して「OK」を押すと、編集画面に進みます。「キャンセル」で読み込みを取り消せます。
3. **開始・終了位置を決める**
   - 「切り出し範囲」の「開始」「終了」のスライダーを動かします。地図とグラフ上の位置が連動します。
   - 行の名前を押してから、地図や速度グラフをタップして指定することもできます。もう一度押すと解除されます。
   - 地図は、ピンチ・ドラッグ・＋／－ボタンで拡大縮小・移動します。「全」で全体、「選」で選択範囲を表示します。
4. **途中を削除する（任意）**
   - 「一部を削除」のスライダーで範囲を決め、「この区間を削除に追加」を押します。複数の区間を追加できます。「取消」で戻せます。
5. **書き出す**
   - 「トラック名」を入力します。
   - 「削除した部分の扱い」を選びます。通常は「トラックを分け、間を線で結ばない（推奨）」です。
   - 必要なら「範囲内のウェイポイント（出発・停車地点）も残す」にチェックを入れます。
   - 「GPXを保存」を押し、共有シートから「ファイルに保存」などを選びます。「内容をコピー」も使えます。
6. **Reliveなどに取り込む**
   - 保存したGPXを、取り込み先のアプリで読み込みます。

### ホーム画面に追加する（iPhone）

Safariで公開ページを開き、共有ボタンから「ホーム画面に追加」を選びます。アイコンは、地図とはさみの絵柄です。

## 対応するGPX

- トラック（`trk`／`trkseg`／`trkpt`）がある、GPX 1.1形式のファイルに対応します。
- ルート（`rte`）のみのファイルには対応していません。
- 各点に時刻（`time`）があると、時間のスライダーや速度の表示が使えます。時刻がない場合は、点の順で操作します。
- 緯度・経度・標高・時刻は、元の文字列のまま書き出します。

## 注意事項

- 背景地図は国土地理院の地理院タイル、またはOpenStreetMapを使います（出典は画面右下に表示されます）。表示にはインターネット接続が必要です。
- OpenStreetMapの公式タイルサーバーは寄付で運営されており、可用性の保証はありません。画面に表示する分だけを読み込み、先読みや保存は行いません（[Tile Usage Policy](https://operations.osmfoundation.org/policies/tiles/)）。ブラウザからの利用のため、アプリ名を含むUser-Agentは送信できません。
- 選んだ背景地図は、ブラウザ内（`localStorage`）に保存します。外部には送信しません。
- 最高速度は、GPSの誤差による一時的な外れ値を除いた目安の値です。
- 平均間隔は、STOP（停止）のウェイポイントに対応する、時刻の飛びを除いて計算します。
- 書き出したGPXは、必ず取り込み先のアプリで表示を確認してください。
